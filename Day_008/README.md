# Day 052 - Customer Churn Prediction using Logistic Regression

## Overview

This project focuses on binary classification using Logistic Regression.

The model predicts whether a customer is likely to churn based on customer information such as age, monthly charges, tenure, and contract type.

## Dataset

The dataset contains the following features:

- Age
- MonthlyCharges
- Tenure
- Contract

### Target

- Churn

`No` is represented as `0` and `Yes` is represented as `1`.
