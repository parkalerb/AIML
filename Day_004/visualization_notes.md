# Data Visualization Notes

## 📖 Introduction

Data Visualization is the process of representing data using graphical elements such as charts, plots, and graphs.

In Machine Learning, visualization helps us understand datasets before building models.

It can help identify:

- Patterns
- Trends
- Distributions
- Relationships
- Outliers
- Correlations

---

# 📊 Why Data Visualization?

Raw data can be difficult to understand by simply looking at rows and columns.

Visualization converts numerical data into graphical representations, making important patterns easier to identify.

### Main Benefits

- Understand data quickly
- Identify patterns
- Detect outliers
- Understand distributions
- Find relationships between features
- Support better decision-making
- Help during Machine Learning preprocessing
