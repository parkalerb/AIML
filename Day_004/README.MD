# 🎤 Interview Preparation

### Why is Data Visualization important?

Data Visualization helps identify patterns, trends, distributions, relationships, and outliers that may not be obvious from raw data.

### What is a Histogram?

A Histogram represents the distribution of numerical data using bins.

### What is a Scatter Plot?

A Scatter Plot shows the relationship between two numerical variables using individual data points.

### What is Correlation?

Correlation measures the strength and direction of a linear relationship between two numerical variables.

### Matplotlib vs Seaborn

Matplotlib is a general-purpose visualization library that provides detailed control over plots, while Seaborn provides a higher-level interface for statistical visualizations.
