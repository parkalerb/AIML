# NumPy Notes

## What is NumPy?

NumPy (Numerical Python) is a Python library used for fast numerical computations.

---

## Why NumPy?

- Faster than Python Lists
- Less Memory
- Mathematical Operations
- Used in AI, ML and Data Science

---

## ndarray

The core object of NumPy.

Example:

```python
arr = np.array([1,2,3])
```

---

## Shape

Number of rows and columns.

Example

(2,3)

---

## Dimension

1D

2D

3D

---

## Vectorization

Applying operations on the entire array without loops.

Example

```python
arr + 10
```

---

## List vs ndarray

| Python List | NumPy ndarray |
|-------------|---------------|
| Slow | Fast |
| More Memory | Less Memory |
| No Vectorization | Supports Vectorization |
